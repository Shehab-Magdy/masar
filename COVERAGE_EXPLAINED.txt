🎯 WHAT IS CODE COVERAGE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Definition: The percentage of your code that is executed by your tests.

Example:

    CODE:                           TESTS:
    ─────────────────────           ──────────────────
    function add(a, b):             test_add_positive():
        if a > 0:                       assert add(5, 3) == 8
            return a + b            
        else:                        COVERAGE RESULT:
            return 0                ✓ Function executed
                                    ✓ if branch executed
                                    ✓ return a + b executed
                                    ✗ else branch NOT executed
                                    
                                    Coverage: 75% (3 of 4 paths)
